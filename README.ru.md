# LLM Tutorial · Большие языковые модели с нуля до эксперта

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · **Русский**

Курс по большим языковым моделям (LLM), рассчитанный на **абсолютных новичков**: начинаем с вопроса «что такое LLM?», восполняем нужную математику и Python, своими руками пишем нейросеть, движок автодифференцирования и маленький GPT, а затем проходим предобучение, выравнивание, инференс и развёртывание, RAG, агентов и передний край 2026 года.

- 🧭 **Действительно с нуля**: хватает школьной математики; каждое понятие объясняется с интуиции и сопровождается запускаемым кодом
- 🛠️ **Строим сами, а не только вызываем библиотеки**: токенизатор (BPE), внимание, трансформер, сэмплирование, LoRA, функция потерь DPO, преимущества GRPO, квантизация, спекулятивное декодирование, векторный поиск… сначала на чистом Python
- ✍️ **Задания в каждом уроке**, задачи на программирование **проверяются автоматически**
- 🌏 **4 языка**: упрощённый и традиционный китайский, английский, русский; интерфейс программы также на японском, корейском, испанском, французском и немецком
- 🖥️ **Программа для компьютера** (Windows, macOS, Linux) или обучение в браузере на [yeraldo.com/learn](https://yeraldo.com/learn)
- 🆕 **Актуально**: MoE, GQA/MLA, RoPE, FlashAttention, FP8, DPO, GRPO и RL с проверяемыми наградами, модели-рассуждатели, MCP, контекст-инжиниринг и многое другое

## Как учиться

**Программа (рекомендуется)**: скачайте архив для своей системы на странице [Releases](https://github.com/YeraldoSmith/LLM-Tutorial/releases) и запустите `LLMTutorial`. Python встроен, поэтому для большинства заданий частей 1–3 ничего устанавливать не нужно. В некоторых уроках используются `numpy` и `torch` — установите их через `pip install`, как подскажет урок.

**Из исходников** (Python 3.11+):

```bash
git clone https://github.com/YeraldoSmith/LLM-Tutorial.git
cd LLM-Tutorial
pip install -r app/requirements.txt
python app/run.py
```

**На GitHub**: каждый урок — папка с файлами `zh-CN.md`, `zh-TW.md`, `en.md` и `ru.md`; тесты и эталонные решения — в `exercises.toml`.

**В браузере**: <https://yeraldo.com/learn> — код на Python выполняется прямо в браузере.
