## 2.1 Какой компьютер нужен?

**Хорошая новость: для частей 1–3 видеокарта не нужна.** Ядро курса — нейросети, автодифференцирование, внимание, маленький GPT своими руками — реализовано на чистом Python или на крошечных моделях, которые работают на обычном ноутбуке.

| Когда | Что нужно |
|-------|-----------|
| части 1–3 | любой компьютер, на котором работает Python. В программу курса Python встроен; большинство заданий работает сразу |
| часть 3, урок 6 (обучение маленького GPT), эксперименты частей 4–5 | PyTorch; видеокарта NVIDIA или чип Apple M-серии сильно ускоряют, иначе — бесплатный облачный GPU |
| часть 6 (запуск открытых моделей локально) | 8 ГБ ОЗУ для моделей 1–4B; 16–32 ГБ ОЗУ или видеопамяти для квантизованных моделей 7–14B |
| часть 7 (приложения) | обычный компьютер и ключ API модели (или локальная модель) |

### Почему важны GPU?

Вычисления в нейросети — это почти сплошь **огромное количество умножений и сложений**. CPU похож на нескольких гениальных профессоров, решающих задачи по очереди; GPU — на тысячи школьников, которые умеют только простую арифметику, но считают **одновременно**. Для нейросетей второе гораздо быстрее — обучение и запуск LLM происходят на GPU.

- **NVIDIA**: самая полная экосистема (CUDA), первый выбор для PyTorch и других фреймворков.
- **Apple M-серия**: поддерживается в PyTorch через бэкенд MPS; общая память позволяет Mac запускать довольно большие модели.
- **AMD**: поддержка через ROCm, лучше всего в Linux.

## 2.2 Установка Python и uv

Если вы учитесь в программе курса, для частей 1–3 почти ничего ставить не нужно. Чтобы запускать код курса в своём окружении (рекомендуется — дальше понадобятся numpy и PyTorch), установите:

1. **Python 3.12 или новее**: см. [Our-tutorial, «Установка инструментов»](https://github.com/YeraldoSmith/Our-tutorial/tree/HEAD/courses/start/04-install-tools).
2. **uv** — очень быстрый менеджер пакетов и окружений Python, который становится новым стандартом для Python-проектов.

```console
# Windows
winget install -e --id astral-sh.uv
# macOS
brew install uv
# Linux / macOS
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### Проект для этого курса

```console
mkdir llm-study
cd llm-study
uv init
uv add numpy matplotlib jupyter
uv run python -c "import numpy; print(numpy.__version__)"
```

`uv init` создаёт проект, `uv add` устанавливает библиотеки и записывает их в `pyproject.toml`, `uv run` выполняет команду в **виртуальном окружении** проекта.

> [!NOTE]
> **Виртуальное окружение** (virtual environment) — отдельный «ящик библиотек» для каждого проекта: библиотеки одного проекта не влияют на другие и на системный Python. uv создаёт и использует его сам. Если привычнее pip: `python -m venv .venv`, затем `pip install`.

### Установка PyTorch (с урока 5 части 2)

```console
uv add torch
```

В Windows/Linux с видеокартой NVIDIA нужна сборка с CUDA: выберите свою систему на <https://pytorch.org/get-started/locally/> — там будет нужная команда. Проверка:


## 2.3 Jupyter: блокноты для экспериментов

Многие руководства по ИИ и исследовательские проекты используют **блокноты Jupyter**: код разбит на «ячейки», которые запускаются по одной, а результат (включая графики) виден прямо под ними — идеально для экспериментов.

## 2.6 Практика: сколько памяти нужно модели?

Чтобы запустить модель, **все её параметры должны поместиться в память (ОЗУ или видеопамять)**. Сколько байт занимает параметр, зависит от точности:

| Точность | Байт на параметр | Примечание |
|----------|------------------|------------|
| FP32 (одинарная) | 4 | классическая точность обучения |
| BF16 / FP16 (половинная) | 2 | обычная точность для обучения и инференса сегодня |
| INT8 / FP8 | 1 | 8-битная квантизация |
| INT4 | 0,5 | 4-битная квантизация, чаще всего для локального запуска |

Итак: **память (ГБ) ≈ параметры (млрд) × байт на параметр**. Модель 7B в BF16: 7 × 2 = 14 ГБ; в 4 битах: 7 × 0,5 = 3,5 ГБ. (Для работы нужно ещё место под промежуточные результаты и KV-кэш — об этом в части 6.)

```python
def model_memory_gb(params_billion, bytes_per_param):
    return params_billion * bytes_per_param

for name, size in [("маленькая 1.5B", 1.5), ("7B", 7), ("70B", 70)]:
    print(f"{name}: BF16 около {model_memory_gb(size, 2):.1f} ГБ, "
          f"4 бита около {model_memory_gb(size, 0.5):.1f} ГБ")
```

> [!TIP]
> Практическое правило: для комфортной локальной работы квантизованная модель должна занимать не больше 60–70% вашей ОЗУ (или видеопамяти).

## 2.8 Итоги

- Для частей 1–3 GPU не нужен; для обучения и запуска крупных моделей GPU (NVIDIA / Apple silicon) или облачный GPU намного быстрее.
- Python 3.12+ и uv: `uv init`, `uv add`, `uv run`; виртуальные окружения разделяют библиотеки проектов.
- Jupyter удобен для экспериментов; Colab и Kaggle дают бесплатные GPU.
- Hugging Face — главная площадка открытых моделей.
- Оценка памяти: **ГБ ≈ параметры (B) × байт на параметр** (FP32=4, BF16=2, INT8=1, INT4=0,5).
