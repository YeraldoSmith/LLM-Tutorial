# 5. 导数与梯度：模型是怎么「学习」的

> 🎯 **本课目标**：直观理解导数是「变化率」；用代码近似计算导数；理解梯度下降——所有神经网络的学习方法；体会学习率的影响；认识偏导数、梯度向量和链式法则（反向传播的基础）。
>
> ⏱ **预计用时**：60 分钟　｜　📋 **前置知识**：第 3、4 课；知道 x² 是什么意思

训练一个大模型，说到底就是：**有一个衡量「错得有多离谱」的数字（叫损失 loss），不断微调几十亿个参数，让这个数字变小。** 怎么知道每个参数该往大调还是往小调？答案就是**导数**。

## 5.1 导数：变化有多快

想象你在山坡上，脚下的高度随位置变化。**导数**（derivative）回答的问题是：**往前走一小步，高度会变化多少？**

- 导数为正：往右走会变高（上坡）；
- 导数为负：往右走会变低（下坡）；
- 导数为 0：平地（可能是山顶或谷底）；
- 导数的绝对值越大，坡越陡。

数学上，函数 `f` 在 `x` 处的导数写作 `f'(x)`，定义是：把 `x` 变化一个很小的量 `h`，看 `f` 变化了多少，再除以 `h`。

```formula
f'(x) ≈ ( f(x + h) − f(x − h) ) / (2h)        （h 很小，比如 0.00001）
```

不需要会推导公式，**用代码就能算**：

```python
def f(x):
    return x ** 2

def derivative(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)

for x in [-2, 0, 1, 3]:
    print(f"x = {x:>2}  f(x) = {f(x):>2}  斜率 ≈ {derivative(f, x):.4f}")
```

输出：

```text
x = -2  f(x) =  4  斜率 ≈ -4.0000
x =  0  f(x) =  0  斜率 ≈ 0.0000
x =  1  f(x) =  1  斜率 ≈ 2.0000
x =  3  f(x) =  9  斜率 ≈ 6.0000
```

可以看出，`x²` 的导数正好是 `2x`。下面是几个常用的导数，**知道结果就好，不用记推导**：

| 函数 | 导数 |
|------|------|
| `c`（常数） | `0` |
| `x` | `1` |
| `x²` | `2x` |
| `xⁿ` | `n·xⁿ⁻¹` |
| `eˣ` | `eˣ`（它自己！） |
| `ln x` | `1/x` |
| `a·f(x)` | `a·f'(x)` |
| `f(x) + g(x)` | `f'(x) + g'(x)` |

## 5.2 梯度下降：沿着下坡走

假设我们想找到 `f(x) = (x − 3)²` 的最小值。（答案显然是 `x = 3`，但请假装不知道——就像我们不知道几十亿个参数的最佳值。）

**梯度下降**（gradient descent）的思路非常朴素：**蒙着眼睛下山**——摸一下脚下的坡往哪边倾斜，就朝下坡方向走一小步，重复。

```formula
x_新 = x_旧 − 学习率 × f'(x_旧)
```

- 导数为正（上坡在右边）→ `x` 减小，往左走；
- 导数为负（上坡在左边）→ `x` 增大，往右走；
- **学习率**（learning rate，常写作 `lr`）控制每一步走多远。

```python
def f(x):
    return (x - 3) ** 2

def df(x):
    return 2 * (x - 3)          # (x - 3)² 的导数

x = 0.0                          # 随便从一个地方出发
lr = 0.1
for step in range(1, 21):
    x = x - lr * df(x)
    if step % 4 == 0:
        print(f"第 {step:2d} 步：x = {x:.4f}，f(x) = {f(x):.6f}")
```

`x` 一步步逼近 3，`f(x)` 一步步逼近 0。**这就是神经网络学习的全部秘密**——只不过参数不是 1 个，而是几十亿个；函数不是 `(x−3)²`，而是「模型在训练数据上预测错得有多离谱」。

### 学习率：太小、太大都不行

```python
def df(x):
    return 2 * (x - 3)

for lr in [0.01, 0.1, 0.9, 1.1]:
    x = 0.0
    for _ in range(20):
        x = x - lr * df(x)
    print(f"学习率 {lr:<4}：20 步后 x = {x:.4f}")
```

- `0.01`：太小，走得很慢，20 步还没到；
- `0.1`：合适；
- `0.9`：每步都「跨过」最低点，来回震荡，但仍在收敛；
- `1.1`：太大，越跳越远，**发散**了！

> [!TIP]
> 训练大模型时，学习率是最重要的「超参数」之一（需要人来选的设置）。训练开始时通常先让学习率从很小慢慢升高（warmup），之后再逐渐降低（decay），第二部分会讲。

## 5.3 多个变量：偏导数与梯度

真实的模型有很多参数。对于 `f(x, y) = x² + 3y²`，我们分别看「只动 `x`」和「只动 `y`」时 `f` 怎么变，这叫**偏导数**（partial derivative）：

```text
∂f/∂x = 2x          （把 y 当常数）
∂f/∂y = 6y          （把 x 当常数）
```

把所有偏导数排成一个向量，就是**梯度**（gradient）：`∇f = [∂f/∂x, ∂f/∂y]`。梯度指向**上升最快**的方向，所以沿着**负梯度**走，下降最快。

```python
def f(x, y):
    return x ** 2 + 3 * y ** 2

def grad(x, y):
    return 2 * x, 6 * y

x, y = 4.0, -2.0
lr = 0.1
for step in range(1, 31):
    gx, gy = grad(x, y)
    x, y = x - lr * gx, y - lr * gy
    if step % 10 == 0:
        print(f"第 {step} 步：x = {x:.4f}, y = {y:.4f}, f = {f(x, y):.6f}")
```

对一个有 70 亿参数的模型，梯度就是一个有 70 亿个数字的向量，每个数字告诉对应的参数「往哪边调、调多少」。

## 5.4 链式法则：一环扣一环

神经网络是一层套一层的函数。比如 `y = g(x)`、`z = f(y)`，`z` 对 `x` 的导数怎么算？

**链式法则**（chain rule）：**变化率相乘**。

```formula
dz/dx = dz/dy × dy/dx
```

直觉：齿轮传动。如果 `x` 每转 1 圈 `y` 转 3 圈，`y` 每转 1 圈 `z` 转 2 圈，那么 `x` 转 1 圈 `z` 就转 3 × 2 = 6 圈。

例子：`z = (3x + 1)²`。设 `y = 3x + 1`，则 `z = y²`：

```text
dy/dx = 3
dz/dy = 2y
dz/dx = 2y × 3 = 6(3x + 1)
```

用代码验证：

```python
def z_of_x(x):
    return (3 * x + 1) ** 2

def derivative(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)

x = 2.0
print("数值导数：", round(derivative(z_of_x, x), 4))
print("链式法则：", 6 * (3 * x + 1))
```

> [!IMPORTANT]
> 链式法则是**反向传播**（backpropagation）的数学基础：从最后的损失开始，一层一层往回乘，就能高效地算出每一个参数的梯度。第二部分第 4 课，你会亲手实现它。

## 5.5 为什么不用数值导数训练模型？

`(f(x+h) − f(x−h)) / 2h` 每算一个参数的导数，就要把整个模型运行两次。70 亿参数就要运行 140 亿次——太慢了。反向传播利用链式法则，**只需要大约两次运行的计算量，就能得到所有参数的梯度**。不过数值导数在调试时很有用：可以用它检查反向传播算得对不对（叫梯度检查，gradient check）。

## 5.6 小结

- **导数**是变化率：正为上坡、负为下坡、0 为平地；可以用 `(f(x+h) − f(x−h)) / 2h` 近似计算。
- **梯度下降**：`参数 ← 参数 − 学习率 × 导数`，反复执行，让函数值越来越小——这就是模型学习的方法。
- **学习率**太小收敛慢，太大会震荡甚至发散。
- 多个变量时，**偏导数**组成**梯度**向量；沿负梯度方向下降最快。
- **链式法则**：复合函数的导数等于各环节导数相乘，是反向传播的基础。

输入一行三个数：起点 `x0`、学习率 `lr`、步数 `n`。对 `f(x) = (x − 5)²` 执行 `n` 步梯度下降（导数为 `2(x − 5)`），输出最后的 `x`，保留 4 位小数。

### 练习 3：学习率太大

用梯度下降训练时，损失不但没有下降，反而越来越大、最后变成了 `inf`（无穷大）。最可能的原因是？

- 学习率太小
- 学习率太大
- 数据太多
- 电脑太慢

<details>
<summary>答案与解析</summary>

学习率太大时，每一步都跨过最低点并且越跳越远，于是发散。降低学习率通常就能解决。
</details>

### 练习 4：链式法则

`y = 4x`，`z = y²`。当 `x = 1` 时，`dz/dx` 等于多少？

- 4
- 8
- 16
- 32

<details>
<summary>答案与解析</summary>

`dz/dy = 2y = 8`（因为 `y = 4`），`dy/dx = 4`，相乘得 32。也可以直接展开：`z = 16x²`，导数 `32x`，在 1 处为 32。
</details>
