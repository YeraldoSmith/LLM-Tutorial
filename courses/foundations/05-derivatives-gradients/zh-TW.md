# 5. 導數與梯度：模型是怎麼「學習」的

> 🎯 **本課目標**：直觀理解導數是「變化率」；用程式碼近似計算導數；理解梯度下降——所有神經網路的學習方法；體會學習率的影響；認識偏導數、梯度向量和鏈式法則（反向傳播的基礎）。
>
> ⏱ **預計用時**：60 分鐘　｜　📋 **前置知識**：第 3、4 課；知道 x² 是什麼意思

訓練一個大模型，說到底就是：**有一個衡量「錯得有多離譜」的數字（叫損失 loss），不斷微調幾十億個引數，讓這個數字變小。** 怎麼知道每個引數該往大調還是往小調？答案就是**導數**。

## 5.1 導數：變化有多快

想象你在山坡上，腳下的高度隨位置變化。**導數**（derivative）回答的問題是：**往前走一小步，高度會變化多少？**

- 導數為正：往右走會變高（上坡）；
- 導數為負：往右走會變低（下坡）；
- 導數為 0：平地（可能是山頂或谷底）；
- 導數的絕對值越大，坡越陡。

數學上，函式 `f` 在 `x` 處的導數寫作 `f'(x)`，定義是：把 `x` 變化一個很小的量 `h`，看 `f` 變化了多少，再除以 `h`。

```formula
f'(x) ≈ ( f(x + h) − f(x − h) ) / (2h)        （h 很小，比如 0.00001）
```

不需要會推導公式，**用程式碼就能算**：

```python
def f(x):
    return x ** 2

def derivative(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)

for x in [-2, 0, 1, 3]:
    print(f"x = {x:>2}  f(x) = {f(x):>2}  斜率 ≈ {derivative(f, x):.4f}")
```

輸出：

```text
x = -2  f(x) =  4  斜率 ≈ -4.0000
x =  0  f(x) =  0  斜率 ≈ 0.0000
x =  1  f(x) =  1  斜率 ≈ 2.0000
x =  3  f(x) =  9  斜率 ≈ 6.0000
```

可以看出，`x²` 的導數正好是 `2x`。下面是幾個常用的導數，**知道結果就好，不用記推導**：

| 函式 | 導數 |
|------|------|
| `c`（常數） | `0` |
| `x` | `1` |
| `x²` | `2x` |
| `xⁿ` | `n·xⁿ⁻¹` |
| `eˣ` | `eˣ`（它自己！） |
| `ln x` | `1/x` |
| `a·f(x)` | `a·f'(x)` |
| `f(x) + g(x)` | `f'(x) + g'(x)` |

## 5.2 梯度下降：沿著下坡走

假設我們想找到 `f(x) = (x − 3)²` 的最小值。（答案顯然是 `x = 3`，但請假裝不知道——就像我們不知道幾十億個引數的最佳值。）

**梯度下降**（gradient descent）的思路非常樸素：**蒙著眼睛下山**——摸一下腳下的坡往哪邊傾斜，就朝下坡方向走一小步，重複。

```formula
x_新 = x_舊 − 學習率 × f'(x_舊)
```

- 導數為正（上坡在右邊）→ `x` 減小，往左走；
- 導數為負（上坡在左邊）→ `x` 增大，往右走；
- **學習率**（learning rate，常寫作 `lr`）控制每一步走多遠。

```python
def f(x):
    return (x - 3) ** 2

def df(x):
    return 2 * (x - 3)          # (x - 3)² 的導數

x = 0.0                          # 隨便從一個地方出發
lr = 0.1
for step in range(1, 21):
    x = x - lr * df(x)
    if step % 4 == 0:
        print(f"第 {step:2d} 步：x = {x:.4f}，f(x) = {f(x):.6f}")
```

`x` 一步步逼近 3，`f(x)` 一步步逼近 0。**這就是神經網路學習的全部秘密**——只不過引數不是 1 個，而是幾十億個；函式不是 `(x−3)²`，而是「模型在訓練資料上預測錯得有多離譜」。

### 學習率：太小、太大都不行

```python
def df(x):
    return 2 * (x - 3)

for lr in [0.01, 0.1, 0.9, 1.1]:
    x = 0.0
    for _ in range(20):
        x = x - lr * df(x)
    print(f"學習率 {lr:<4}：20 步後 x = {x:.4f}")
```

- `0.01`：太小，走得很慢，20 步還沒到；
- `0.1`：合適；
- `0.9`：每步都「跨過」最低點，來回震盪，但仍在收斂；
- `1.1`：太大，越跳越遠，**發散**了！

> [!TIP]
> 訓練大模型時，學習率是最重要的「超引數」之一（需要人來選的設定）。訓練開始時通常先讓學習率從很小慢慢升高（warmup），之後再逐漸降低（decay），第二部分會講。

## 5.3 多個變數：偏導數與梯度

真實的模型有很多引數。對於 `f(x, y) = x² + 3y²`，我們分別看「只動 `x`」和「只動 `y`」時 `f` 怎麼變，這叫**偏導數**（partial derivative）：

```text
∂f/∂x = 2x          （把 y 當常數）
∂f/∂y = 6y          （把 x 當常數）
```

把所有偏導數排成一個向量，就是**梯度**（gradient）：`∇f = [∂f/∂x, ∂f/∂y]`。梯度指向**上升最快**的方向，所以沿著**負梯度**走，下降最快。

```python
def f(x, y):
    return x ** 2 + 3 * y ** 2

def grad(x, y):
    return 2 * x, 6 * y

x, y = 4.0, -2.0
lr = 0.1
for step in range(1, 31):
    gx, gy = grad(x, y)
    x, y = x - lr * gx, y - lr * gy
    if step % 10 == 0:
        print(f"第 {step} 步：x = {x:.4f}, y = {y:.4f}, f = {f(x, y):.6f}")
```

對一個有 70 億引數的模型，梯度就是一個有 70 億個數字的向量，每個數字告訴對應的引數「往哪邊調、調多少」。

## 5.4 鏈式法則：一環扣一環

神經網路是一層套一層的函式。比如 `y = g(x)`、`z = f(y)`，`z` 對 `x` 的導數怎麼算？

**鏈式法則**（chain rule）：**變化率相乘**。

```formula
dz/dx = dz/dy × dy/dx
```

直覺：齒輪傳動。如果 `x` 每轉 1 圈 `y` 轉 3 圈，`y` 每轉 1 圈 `z` 轉 2 圈，那麼 `x` 轉 1 圈 `z` 就轉 3 × 2 = 6 圈。

例子：`z = (3x + 1)²`。設 `y = 3x + 1`，則 `z = y²`：

```text
dy/dx = 3
dz/dy = 2y
dz/dx = 2y × 3 = 6(3x + 1)
```

用程式碼驗證：

```python
def z_of_x(x):
    return (3 * x + 1) ** 2

def derivative(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)

x = 2.0
print("數值導數：", round(derivative(z_of_x, x), 4))
print("鏈式法則：", 6 * (3 * x + 1))
```

> [!IMPORTANT]
> 鏈式法則是**反向傳播**（backpropagation）的數學基礎：從最後的損失開始，一層一層往回乘，就能高效地算出每一個引數的梯度。第二部分第 4 課，你會親手實現它。

## 5.5 為什麼不用數值導數訓練模型？

`(f(x+h) − f(x−h)) / 2h` 每算一個引數的導數，就要把整個模型執行兩次。70 億引數就要執行 140 億次——太慢了。反向傳播利用鏈式法則，**只需要大約兩次執行的計算量，就能得到所有引數的梯度**。不過數值導數在除錯時很有用：可以用它檢查反向傳播算得對不對（叫梯度檢查，gradient check）。

## 5.6 小結

- **導數**是變化率：正為上坡、負為下坡、0 為平地；可以用 `(f(x+h) − f(x−h)) / 2h` 近似計算。
- **梯度下降**：`引數 ← 引數 − 學習率 × 導數`，反覆執行，讓函式值越來越小——這就是模型學習的方法。
- **學習率**太小收斂慢，太大會震盪甚至發散。
- 多個變數時，**偏導數**組成**梯度**向量；沿負梯度方向下降最快。
- **鏈式法則**：複合函式的導數等於各環節導數相乘，是反向傳播的基礎。

### 練習 3：學習率太大

用梯度下降訓練時，損失不但沒有下降，反而越來越大、最後變成了 `inf`（無窮大）。最可能的原因是？

- 學習率太小
- 學習率太大
- 資料太多
- 電腦太慢

<details>
<summary>答案與解析</summary>

學習率太大時，每一步都跨過最低點並且越跳越遠，於是發散。降低學習率通常就能解決。
</details>

### 練習 4：鏈式法則

`y = 4x`，`z = y²`。當 `x = 1` 時，`dz/dx` 等於多少？

- 4
- 8
- 16
- 32

<details>
<summary>答案與解析</summary>

`dz/dy = 2y = 8`（因為 `y = 4`），`dy/dx = 4`，相乘得 32。也可以直接展開：`z = 16x²`，導數 `32x`，在 1 處為 32。
</details>
