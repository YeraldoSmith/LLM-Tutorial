# 5. Производные и градиенты: как модели «учатся»

> 🎯 **Цели урока**: интуитивно понять производную как «скорость изменения»; приближённо вычислять производные кодом; понять градиентный спуск — способ обучения любой нейросети; увидеть влияние скорости обучения; познакомиться с частными производными, градиентом и цепным правилом (основой обратного распространения).
>
> ⏱ **Время**: 60 минут　|　📋 **Что нужно знать**: уроки 3 и 4; что такое x²

Обучение LLM в конечном счёте сводится к следующему: **есть число, которое показывает, «насколько модель ошибается» (функция потерь, loss), и мы снова и снова чуть-чуть подстраиваем миллиарды параметров, чтобы это число уменьшалось.** Как узнать, увеличивать или уменьшать каждый параметр? С помощью **производных**.

## 5.1 Производная: как быстро всё меняется

Представьте, что вы стоите на склоне холма и высота зависит от того, где вы стоите. **Производная** отвечает на вопрос: **если сделать крошечный шаг вперёд, насколько изменится высота?**

- производная положительна: шаг вправо ведёт вверх (подъём);
- отрицательна: шаг вправо ведёт вниз (спуск);
- равна нулю: ровное место (возможно, вершина или дно впадины);
- чем больше её модуль, тем круче склон.

Производная `f` в точке `x` обозначается `f'(x)`: меняем `x` на крошечную величину `h`, смотрим, насколько изменилась `f`, и делим на `h`.

```formula
f'(x) ≈ ( f(x + h) − f(x − h) ) / (2h)        (h очень мало, например 0.00001)
```

Выводить формулы не нужно — **посчитает код**:

```python
def f(x):
    return x ** 2

def derivative(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)

for x in [-2, 0, 1, 3]:
    print(f"x = {x:>2}  f(x) = {f(x):>2}  наклон ≈ {derivative(f, x):.4f}")
```

Вывод:

```text
x = -2  f(x) =  4  наклон ≈ -4.0000
x =  0  f(x) =  0  наклон ≈ 0.0000
x =  1  f(x) =  1  наклон ≈ 2.0000
x =  3  f(x) =  9  наклон ≈ 6.0000
```

Производная `x²` — ровно `2x`. Вот несколько распространённых производных — **достаточно знать результат, вывод не нужен**:

| Функция | Производная |
|---------|-------------|
| `c` (константа) | `0` |
| `x` | `1` |
| `x²` | `2x` |
| `xⁿ` | `n·xⁿ⁻¹` |
| `eˣ` | `eˣ` (она сама!) |
| `ln x` | `1/x` |
| `a·f(x)` | `a·f'(x)` |
| `f(x) + g(x)` | `f'(x) + g'(x)` |

## 5.2 Градиентный спуск: идём вниз

Пусть нужно найти минимум `f(x) = (x − 3)²`. (Очевидно, `x = 3`, но представим, что мы не знаем — так же, как не знаем лучших значений миллиардов параметров.)

**Градиентный спуск** (gradient descent) удивительно прост: **спускаемся с горы с завязанными глазами** — нащупываем, куда наклонена земля, делаем маленький шаг вниз, повторяем.

```formula
x_новое = x_старое − скорость_обучения × f'(x_старое)
```

- производная положительна (подъём справа) → `x` уменьшается, шаг влево;
- отрицательна (подъём слева) → `x` увеличивается, шаг вправо;
- **скорость обучения** (learning rate, часто `lr`) задаёт размер шага.

```python
def f(x):
    return (x - 3) ** 2

def df(x):
    return 2 * (x - 3)          # производная (x - 3)²

x = 0.0                          # стартуем откуда угодно
lr = 0.1
for step in range(1, 21):
    x = x - lr * df(x)
    if step % 4 == 0:
        print(f"шаг {step:2d}: x = {x:.4f}, f(x) = {f(x):.6f}")
```

`x` постепенно приближается к 3, а `f(x)` — к 0. **В этом весь секрет обучения нейросетей** — только параметров не один, а миллиарды, и функция не `(x−3)²`, а «насколько неверны предсказания модели на обучающих данных».

### Скорость обучения: ни слишком мала, ни слишком велика

```python
def df(x):
    return 2 * (x - 3)

for lr in [0.01, 0.1, 0.9, 1.1]:
    x = 0.0
    for _ in range(20):
        x = x - lr * df(x)
    print(f"скорость обучения {lr:<4}: после 20 шагов x = {x:.4f}")
```

- `0.01`: слишком мала — медленно, за 20 шагов не дошли;
- `0.1`: в самый раз;
- `0.9`: каждый шаг перепрыгивает минимум и раскачивается, но всё же сходится;
- `1.1`: слишком велика — каждый прыжок дальше прежнего: **расходится**!

> [!TIP]
> При обучении LLM скорость обучения — один из важнейших «гиперпараметров» (настроек, которые выбирает человек). Обычно её сначала плавно поднимают с маленького значения (warmup), а потом постепенно снижают (decay) — об этом в части 2.

## 5.3 Несколько переменных: частные производные и градиент

У настоящих моделей много параметров. Для `f(x, y) = x² + 3y²` смотрим отдельно, как меняется `f`, если двигать только `x` и только `y`, — это **частные производные**:

```text
∂f/∂x = 2x          (y считаем константой)
∂f/∂y = 6y          (x считаем константой)
```

Сложите все частные производные в вектор — получится **градиент**: `∇f = [∂f/∂x, ∂f/∂y]`. Градиент указывает направление **наискорейшего подъёма**, поэтому движение вдоль **минус градиента** даёт самый быстрый спуск.

```python
def f(x, y):
    return x ** 2 + 3 * y ** 2

def grad(x, y):
    return 2 * x, 6 * y

x, y = 4.0, -2.0
lr = 0.1
for step in range(1, 31):
    gx, gy = grad(x, y)
    x, y = x - lr * gx, y - lr * gy
    if step % 10 == 0:
        print(f"шаг {step}: x = {x:.4f}, y = {y:.4f}, f = {f(x, y):.6f}")
```

Для модели на 7 миллиардов параметров градиент — вектор из 7 миллиардов чисел, и каждое подсказывает своему параметру, «куда и насколько сдвинуться».

## 5.4 Цепное правило: звено за звеном

Нейросеть — это функции, вложенные в функции. Если `y = g(x)` и `z = f(y)`, чему равна производная `z` по `x`?

**Цепное правило** (chain rule): **скорости изменения перемножаются**.

```formula
dz/dx = dz/dy × dy/dx
```

Интуиция — шестерёнки. Если на каждый оборот `x` шестерня `y` делает 3 оборота, а на каждый оборот `y` шестерня `z` — 2, то на оборот `x` приходится 3 × 2 = 6 оборотов `z`.

Пример: `z = (3x + 1)²`. Пусть `y = 3x + 1`, тогда `z = y²`:

```text
dy/dx = 3
dz/dy = 2y
dz/dx = 2y × 3 = 6(3x + 1)
```

Проверим кодом:

```python
def z_of_x(x):
    return (3 * x + 1) ** 2

def derivative(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)

x = 2.0
print("численно:       ", round(derivative(z_of_x, x), 4))
print("цепное правило: ", 6 * (3 * x + 1))
```

> [!IMPORTANT]
> Цепное правило — математическая основа **обратного распространения ошибки** (backpropagation): начиная с итоговой функции потерь и перемножая назад слой за слоем, можно эффективно получить градиент каждого параметра. Вы реализуете это сами в уроке 4 части 2.

## 5.5 Почему не обучать численными производными?

`(f(x+h) − f(x−h)) / 2h` прогоняет всю модель дважды ради производной *одного* параметра. При 7 миллиардах параметров — 14 миллиардов прогонов, слишком медленно. Обратное распространение с помощью цепного правила получает **все градиенты примерно за стоимость двух прогонов**. Но численные производные полезны при отладке: ими проверяют правильность обратного распространения (*проверка градиента*, gradient check).

## 5.6 Итоги

- **Производная** — скорость изменения: положительна на подъёме, отрицательна на спуске, ноль на ровном месте; приближается как `(f(x+h) − f(x−h)) / 2h`.
- **Градиентный спуск**: `параметр ← параметр − скорость обучения × производная`, многократно, — так функция уменьшается, так модели и учатся.
- Слишком малая **скорость обучения** — медленная сходимость; слишком большая — колебания или расходимость.
- Для нескольких переменных **частные производные** образуют **градиент**; минус градиент даёт самый быстрый спуск.
- **Цепное правило**: производная композиции равна произведению производных звеньев — основа обратного распространения.

### Задание 3: Слишком большая скорость обучения

При обучении градиентным спуском функция потерь не уменьшается, а растёт и в конце концов становится `inf`. Вероятная причина?

- слишком маленькая скорость обучения
- слишком большая скорость обучения
- слишком много данных
- слишком медленный компьютер

<details>
<summary>Ответ и разбор</summary>

При слишком большой скорости каждый шаг перескакивает минимум и уводит дальше — обучение расходится. Обычно помогает уменьшить скорость обучения.
</details>
