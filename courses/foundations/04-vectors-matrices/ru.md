Почти все вычисления в нейросети — это **действия с векторами и матрицами**. В LLM каждый токен представлен вектором из тысяч чисел, а каждый слой — по сути, умножение матрицы. Без доказательств — только **интуиция + код**.

## 4.1 Вектор: список осмысленных чисел

**Вектор** — это просто **упорядоченный список чисел**. Например, описание человека:

```text
саша = [рост 175, вес 68, возраст 20]
```

Вместе эти три числа образуют трёхмерный вектор; хватит списка Python:

```python
sasha = [175, 68, 20]
print(len(sasha))     # размерность: 3
```

Вектор — это ещё и **стрелка в пространстве**: двумерный вектор `[3, 4]` — стрелка из начала координат на 3 вправо и на 4 вверх.

```text
 y
 4 ┤        ↗ (3, 4)
 3 ┤      ╱
 2 ┤    ╱
 1 ┤  ╱
 0 ┼──┬──┬──┬── x
   0  1  2  3
```

В языковой модели каждый токен представлен вектором (**эмбеддингом**, часть 3, урок 3). Магия в том, что у близких по смыслу слов векторы смотрят в похожих направлениях.

## 4.2 Основные действия с векторами

### Сложение: складываем соответствующие элементы

```python
a = [1, 2, 3]
b = [10, 20, 30]
c = [x + y for x, y in zip(a, b)]
print(c)        # [11, 22, 33]
```

Геометрически: ставим стрелки «хвост к голове».

### Умножение на число: каждое число умножаем на одно и то же

```python
a = [1, 2, 3]
print([2 * x for x in a])     # [2, 4, 6]: вдвое длиннее, направление то же
```

### Длина (норма): теорема Пифагора

Длина `[3, 4]` равна √(3² + 4²) = 5. В любой размерности: **возвести каждое число в квадрат, сложить, извлечь корень**.

```python
import math

def norm(v):
    return math.sqrt(sum(x * x for x in v))

print(norm([3, 4]))        # 5.0
print(norm([1, 2, 2]))     # 3.0
```

## 4.3 Скалярное произведение — главная операция нейросетей

**Скалярное произведение** (dot product): перемножаем соответствующие элементы и всё складываем — получается **одно число**.

```formula
a · b = a₁b₁ + a₂b₂ + … + aₙbₙ
```

```python
def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

print(dot([1, 2, 3], [4, 5, 6]))    # 1×4 + 2×5 + 3×6 = 32
```

Почему это важно? Два взгляда:

**① Взвешенная сумма.** «Нейрон» вычисляет скалярное произведение входов `x` и весов `w`; входы с большими весами влияют сильнее.

```python
def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

# понравится ли фильм? содержание [боевик, мелодрама, комедия] × насколько вам нравится каждый жанр
movie = [0.9, 0.1, 0.4]
my_taste = [2.0, -1.0, 1.0]
print(dot(movie, my_taste))     # 1.8 - 0.1 + 0.4 = 2.1: высокая оценка, скорее понравится
```

**② Совпадают ли направления?** Чем больше векторы смотрят в одну сторону, тем больше скалярное произведение; перпендикулярные дают 0; противоположные — отрицательное число. На этом основан **механизм внимания** в части 3: скалярное произведение решает, насколько связаны два слова.

## 4.4 Косинусное сходство: насколько похожи векторы

Скалярное произведение зависит и от длин векторов. Чтобы сравнивать только **направления**, делим на обе длины и получаем **косинусное сходство** (cosine similarity) от -1 до 1:

```formula
cos(a, b) = (a · b) / (|a| × |b|)
```

| Значение | Смысл |
|----------|-------|
| 1 | одно направление (очень похожи) |
| 0 | перпендикулярны (не связаны) |
| -1 | противоположные направления |

```python
import math

def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

def cosine(a, b):
    return dot(a, b) / (math.sqrt(dot(a, a)) * math.sqrt(dot(b, b)))

# воображаемые трёхмерные «векторы слов»: [животность, королевскость, пол (м+ ж-)]
king  = [0.1, 0.9, 0.8]
queen = [0.1, 0.9, -0.8]
cat   = [0.9, 0.0, 0.0]
print(f"king·queen: {cosine(king, queen):.2f}")
print(f"king·cat:   {cosine(king, cat):.2f}")
```

В **RAG** (генерации с поиском) в части 7 мы будем искать косинусным сходством самые подходящие к вопросу документы среди тысяч.

## 4.5 Матрица: таблица чисел

**Матрица** — таблица чисел из строк и столбцов. У матрицы `2 × 3` 2 строки и 3 столбца:

```python
M = [
    [1, 2, 3],
    [4, 5, 6],
]
rows, cols = len(M), len(M[0])
print(rows, cols)     # 2 3: «форма» (shape) матрицы
print(M[1][2])        # 6: строка 2, столбец 3 (индексы с 0)
```

Полезный взгляд: **матрица — это стопка векторов**, по одному в строке. Пять слов с четырёхмерными векторами образуют матрицу `5 × 4`.

### Транспонирование

Строки превращаются в столбцы: `m × n` становится `n × m`.

```python
M = [[1, 2, 3],
     [4, 5, 6]]
T = [list(col) for col in zip(*M)]
print(T)      # [[1, 4], [2, 5], [3, 6]]
```

`zip(*M)` передаёт каждую строку отдельным аргументом в `zip`, а тот выдаёт столбцы — классический приём транспонирования в Python.

## 4.6 Матрица на вектор: много скалярных произведений сразу

Матрица `W` (`m × n`), умноженная на вектор `x` (длины `n`), даёт вектор длины `m`: **каждая строка W скалярно умножается на x**.

```text
        x = [1, 1, 2]
W = [[1, 0, 2],    →  1×1 + 0×1 + 2×2 = 5
     [0, 3, 1]]    →  0×1 + 3×1 + 1×2 = 5
W·x = [5, 5]
```

```python
def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

def matvec(W, x):
    return [dot(row, x) for row in W]

W = [[1, 0, 2],
     [0, 3, 1]]
print(matvec(W, [1, 1, 2]))    # [5, 5]
```

Именно это делает **один слой нейросети**: входной вектор `x` умножается на матрицу весов `W`, получается выходной вектор. Форма `W` задаёт размерности: на входе 3, на выходе 2.

## 4.7 Матрица на матрицу

Произведение `A` (`m × n`) и `B` (`n × p`) — матрица `C` (`m × p`): **элемент C в строке i, столбце j = строка i матрицы A · столбец j матрицы B**.

```text
A (2×3)        B (3×2)         C = A·B (2×2)
[1 2 3]        [7  8]          [1·7+2·9+3·11   1·8+2·10+3·12]   [ 58  64]
[4 5 6]   ×    [9 10]     =    [4·7+5·9+6·11   4·8+5·10+6·12] = [139 154]
               [11 12]
```

```python
def matmul(A, B):
    n = len(B)
    assert all(len(row) == n for row in A), "число столбцов A должно равняться числу строк B"
    cols = list(zip(*B))                 # столбцы B
    return [[sum(a * b for a, b in zip(row, col)) for col in cols] for row in A]

A = [[1, 2, 3],
     [4, 5, 6]]
B = [[7, 8],
     [9, 10],
     [11, 12]]
print(matmul(A, B))     # [[58, 64], [139, 154]]
```

> [!IMPORTANT]
> **Правило размерностей**: `(m × n) · (n × p) = (m × p)`. Внутренние `n` должны совпадать; результат получает внешние `m` и `p`. Самая частая ошибка в коде ИИ — несовпадение размерностей (shape mismatch). Приучите себя **писать форму в комментарии на каждом шаге**.

Кроме того, умножение матриц **некоммутативно**: обычно `A·B ≠ B·A` (размерности могут даже не подойти).

## 4.8 Почему GPU хороши в этом?

Тысячи скалярных произведений внутри умножения матриц **независимы**, поэтому их можно считать одновременно — это и есть сила GPU (урок 2). Генерация одного токена LLM требует от миллиардов до сотен миллиардов умножений со сложением. Наша самописная версия медленная, но идея та же самая: в NumPy и PyTorch `A @ B` делает ровно то же, что `matmul`.

```python requires=numpy
import numpy as np
A = np.array([[1, 2, 3], [4, 5, 6]])
B = np.array([[7, 8], [9, 10], [11, 12]])
print(A @ B)
print(A.shape, B.shape, (A @ B).shape)
```

## 4.9 Итоги

- **Вектор** — список чисел и стрелка в пространстве; действия: сложение, умножение на число, длина (корень из суммы квадратов).
- **Скалярное произведение** перемножает соответствующие элементы и складывает; это взвешенная сумма и мера совпадения направлений.
- **Косинусное сходство** = скалярное произведение ÷ обе длины, от -1 до 1; сравнивает похожесть векторов.
- **Матрица** — таблица (стопка векторов); транспонирование — `zip(*M)`.
- Матрица × вектор = каждая строка скалярно на вектор = один слой нейросети.
- Умножение матриц: `(m×n)·(n×p) = (m×p)`, C[i][j] = строка i из A · столбец j из B; некоммутативно; всегда проверяйте размерности.

### Задание 4: Размерности

Какой формы будет произведение матрицы `4 × 3` на матрицу `3 × 5`?

- `4 × 5`
- `3 × 3`
- `5 × 4`
- их нельзя перемножить

<summary>Ответ и разбор</summary>
