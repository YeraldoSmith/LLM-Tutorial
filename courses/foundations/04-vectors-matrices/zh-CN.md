>
> ⏱ **预计用时**：60 分钟　｜　📋 **前置知识**：第 3 课；初中数学（加减乘除、平方、平方根）

神经网络里几乎所有的计算，都是**向量和矩阵的运算**。大模型里，每个词都被表示成一个有几千个数字的向量；模型的每一层，本质上都是一次矩阵乘法。这一课不讲证明，只讲**直觉 + 代码**。

## 4.1 向量：一串有意义的数字

**向量**（vector）就是**按顺序排列的一串数字**。比如描述一个人：

```text
小明 = [身高 175, 体重 68, 年龄 20]
```

这三个数字合起来，就是一个 3 维向量。用 Python 列表就能表示：

```python
xiaoming = [175, 68, 20]
print(len(xiaoming))     # 维度（dimension）：3
```

向量也可以看成**空间里的一个箭头**：2 维向量 `[3, 4]` 是从原点出发、向右 3、向上 4 的箭头。

```text
 y
 4 ┤        ↗ (3, 4)
 3 ┤      ╱
 2 ┤    ╱
 1 ┤  ╱
 0 ┼──┬──┬──┬── x
   0  1  2  3
```

在语言模型里，每个 token 会被表示成一个向量（叫**词向量**或 **embedding**，第三部分第 3 课）。神奇之处在于：意思相近的词，向量在空间里的方向也相近。

## 4.2 向量的基本运算

### 加法：对应位置相加

```python
a = [1, 2, 3]
b = [10, 20, 30]
c = [x + y for x, y in zip(a, b)]
print(c)        # [11, 22, 33]
```

几何意义：把两个箭头首尾相接。

### 数乘：每个数都乘以同一个数

```python
a = [1, 2, 3]
print([2 * x for x in a])     # [2, 4, 6]：箭头变长一倍，方向不变
```

### 长度（模）：勾股定理

向量 `[3, 4]` 的长度是 √(3² + 4²) = 5。推广到任意维度：**每个数平方、加起来、开根号**。

```python
import math

def norm(v):
    return math.sqrt(sum(x * x for x in v))

print(norm([3, 4]))        # 5.0
print(norm([1, 2, 2]))     # 3.0
```

## 4.3 点积：神经网络最重要的运算

**点积**（dot product，也叫内积）：对应位置相乘，再全部加起来，得到**一个数**。

```formula
a · b = a₁b₁ + a₂b₂ + … + aₙbₙ
```

```python
def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

print(dot([1, 2, 3], [4, 5, 6]))    # 1×4 + 2×5 + 3×6 = 32
```

点积为什么重要？两个理解角度：

**① 加权求和**。神经网络里的一个「神经元」做的就是点积：输入 `x` 和权重 `w` 点积，权重大的输入影响大。

```python
def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

# 判断一部电影你会不会喜欢：[动作, 爱情, 喜剧] 的含量 × 你对每类的喜好程度
movie = [0.9, 0.1, 0.4]
my_taste = [2.0, -1.0, 1.0]
print(dot(movie, my_taste))     # 1.8 - 0.1 + 0.4 = 2.1，分数高，你大概会喜欢
```

**② 衡量方向是否一致**。两个向量方向越一致，点积越大；垂直时点积为 0；方向相反时为负数。这正是第三部分「注意力机制」的核心：用点积判断两个词「有多相关」。

## 4.4 余弦相似度：两个向量有多「像」

点积会受向量长度影响。只想比较**方向**时，把点积除以两个长度，得到**余弦相似度**（cosine similarity），范围是 -1 到 1：

```formula
cos(a, b) = (a · b) / (|a| × |b|)
```

| 值 | 含义 |
|----|------|
| 1 | 方向完全相同（非常相似） |
| 0 | 垂直（无关） |
| -1 | 方向完全相反 |

```python
import math

def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

def cosine(a, b):
    return dot(a, b) / (math.sqrt(dot(a, a)) * math.sqrt(dot(b, b)))

# 假想的 3 维「词向量」：[动物性, 王室性, 性别（男+ 女-）]
king  = [0.1, 0.9, 0.8]
queen = [0.1, 0.9, -0.8]
cat   = [0.9, 0.0, 0.0]
print(f"king·queen: {cosine(king, queen):.2f}")
print(f"king·cat:   {cosine(king, cat):.2f}")
```

在第七部分的 **RAG**（检索增强生成）中，我们会用余弦相似度在成千上万篇文档里找出和问题最相关的那几篇。

## 4.5 矩阵：一张数字表格

**矩阵**（matrix）是一个按行和列排列的数字表格。`2 × 3` 矩阵有 2 行 3 列：

```python
M = [
    [1, 2, 3],
    [4, 5, 6],
]
rows, cols = len(M), len(M[0])
print(rows, cols)     # 2 3：这就是矩阵的「形状」(shape)
print(M[1][2])        # 6：第 2 行第 3 列（下标从 0 开始）
```

一种很有用的看法：**矩阵是一摞向量**，每一行是一个向量。比如 5 个词、每个词用 4 维向量表示，就是一个 `5 × 4` 的矩阵。

### 转置

把行变成列：`m × n` 变成 `n × m`。

```python
M = [[1, 2, 3],
     [4, 5, 6]]
T = [list(col) for col in zip(*M)]
print(T)      # [[1, 4], [2, 5], [3, 6]]
```

`zip(*M)` 把每一行拆开作为参数传给 `zip`，正好按列取出——这是 Python 里转置的经典技巧。

## 4.6 矩阵乘向量：一次做很多个点积

矩阵 `W`（`m × n`）乘以向量 `x`（长度 `n`），结果是长度 `m` 的向量：**W 的每一行和 x 做一次点积**。

```text
        x = [1, 1, 2]
W = [[1, 0, 2],    →  1×1 + 0×1 + 2×2 = 5
     [0, 3, 1]]    →  0×1 + 3×1 + 1×2 = 5
W·x = [5, 5]
```

```python
def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

def matvec(W, x):
    return [dot(row, x) for row in W]

W = [[1, 0, 2],
     [0, 3, 1]]
print(matvec(W, [1, 1, 2]))    # [5, 5]
```

这就是**神经网络的一层**在做的事：输入向量 `x`，乘以权重矩阵 `W`，得到输出向量。`W` 的形状决定了输入、输出的维度：`3` 维进，`2` 维出。

## 4.7 矩阵乘矩阵

两个矩阵 `A`（`m × n`）和 `B`（`n × p`）相乘，结果 `C` 是 `m × p`：**C 的第 i 行第 j 列 = A 的第 i 行 和 B 的第 j 列 的点积**。

```text
A (2×3)        B (3×2)         C = A·B (2×2)
[1 2 3]        [7  8]          [1·7+2·9+3·11   1·8+2·10+3·12]   [ 58  64]
[4 5 6]   ×    [9 10]     =    [4·7+5·9+6·11   4·8+5·10+6·12] = [139 154]
               [11 12]
```

```python
def matmul(A, B):
    n = len(B)
    assert all(len(row) == n for row in A), "A 的列数必须等于 B 的行数"
    cols = list(zip(*B))                 # B 的每一列
    return [[sum(a * b for a, b in zip(row, col)) for col in cols] for row in A]

A = [[1, 2, 3],
     [4, 5, 6]]
B = [[7, 8],
     [9, 10],
     [11, 12]]
print(matmul(A, B))     # [[58, 64], [139, 154]]
```

> [!IMPORTANT]
> **形状规则**：`(m × n) · (n × p) = (m × p)`。中间的 `n` 必须相等，才能相乘；结果取两边的 `m` 和 `p`。读 AI 代码时，最常见的错误就是形状对不上（shape mismatch）。养成习惯：**写每一步时在注释里标出形状**。

另外，矩阵乘法**不满足交换律**：一般来说 `A·B ≠ B·A`（甚至形状都可能对不上）。

## 4.8 为什么 GPU 擅长这些？

一次矩阵乘法里，成千上万个点积**互不依赖**，可以同时计算——这正是 GPU 的强项（第 2 课）。一个大模型生成一个 token，要做的矩阵乘法加起来有几十亿到上千亿次乘加运算。我们手写的版本很慢，但原理完全一样；NumPy 里写 `A @ B`，PyTorch 里写 `A @ B` 或 `torch.matmul(A, B)`，做的就是 `matmul` 这件事。

```python requires=numpy
import numpy as np
A = np.array([[1, 2, 3], [4, 5, 6]])
B = np.array([[7, 8], [9, 10], [11, 12]])
print(A @ B)
print(A.shape, B.shape, (A @ B).shape)
```

## 4.9 小结

- **向量**是一串数字，也是空间中的箭头；运算：加法、数乘、长度（平方和开根号）。
- **点积**：对应相乘再相加；既是「加权求和」，也衡量「方向是否一致」。
- **余弦相似度** = 点积 ÷ 两个长度，范围 -1～1，用来比较两个向量有多像。
- **矩阵**是数字表格（一摞向量）；转置用 `zip(*M)`。
- 矩阵乘向量 = 每一行和向量做点积 = 神经网络的一层。
- 矩阵乘法：`(m×n)·(n×p) = (m×p)`，C[i][j] = A 的第 i 行 · B 的第 j 列；不满足交换律；时刻检查形状。
