神經網路裡幾乎所有的計算，都是**向量和矩陣的運算**。大模型裡，每個詞都被表示成一個有幾千個數字的向量；模型的每一層，本質上都是一次矩陣乘法。這一課不講證明，只講**直覺 + 程式碼**。

## 4.1 向量：一串有意義的數字

**向量**（vector）就是**按順序排列的一串數字**。比如描述一個人：

```text
小明 = [身高 175, 體重 68, 年齡 20]
```

這三個數字合起來，就是一個 3 維向量。用 Python 列表就能表示：

```python
xiaoming = [175, 68, 20]
print(len(xiaoming))     # 維度（dimension）：3
```

向量也可以看成**空間裡的一個箭頭**：2 維向量 `[3, 4]` 是從原點出發、向右 3、向上 4 的箭頭。

```text
 y
 4 ┤        ↗ (3, 4)
 3 ┤      ╱
 2 ┤    ╱
 1 ┤  ╱
 0 ┼──┬──┬──┬── x
   0  1  2  3
```

在語言模型裡，每個 token 會被表示成一個向量（叫**詞向量**或 **embedding**，第三部分第 3 課）。神奇之處在於：意思相近的詞，向量在空間裡的方向也相近。

## 4.2 向量的基本運算

### 加法：對應位置相加

```python
a = [1, 2, 3]
b = [10, 20, 30]
c = [x + y for x, y in zip(a, b)]
print(c)        # [11, 22, 33]
```

幾何意義：把兩個箭頭首尾相接。

### 數乘：每個數都乘以同一個數

```python
a = [1, 2, 3]
print([2 * x for x in a])     # [2, 4, 6]：箭頭變長一倍，方向不變
```

### 長度（模）：勾股定理

向量 `[3, 4]` 的長度是 √(3² + 4²) = 5。推廣到任意維度：**每個數平方、加起來、開根號**。

```python
import math

def norm(v):
    return math.sqrt(sum(x * x for x in v))

print(norm([3, 4]))        # 5.0
print(norm([1, 2, 2]))     # 3.0
```

## 4.3 點積：神經網路最重要的運算

**點積**（dot product，也叫內積）：對應位置相乘，再全部加起來，得到**一個數**。

```formula
a · b = a₁b₁ + a₂b₂ + … + aₙbₙ
```

```python
def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

print(dot([1, 2, 3], [4, 5, 6]))    # 1×4 + 2×5 + 3×6 = 32
```

點積為什麼重要？兩個理解角度：

**① 加權求和**。神經網路裡的一個「神經元」做的就是點積：輸入 `x` 和權重 `w` 點積，權重大的輸入影響大。

```python
def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

# 判斷一部電影你會不會喜歡：[動作, 愛情, 喜劇] 的含量 × 你對每類的喜好程度
movie = [0.9, 0.1, 0.4]
my_taste = [2.0, -1.0, 1.0]
print(dot(movie, my_taste))     # 1.8 - 0.1 + 0.4 = 2.1，分數高，你大概會喜歡
```

**② 衡量方向是否一致**。兩個向量方向越一致，點積越大；垂直時點積為 0；方向相反時為負數。這正是第三部分「注意力機制」的核心：用點積判斷兩個詞「有多相關」。

## 4.4 餘弦相似度：兩個向量有多「像」

點積會受向量長度影響。只想比較**方向**時，把點積除以兩個長度，得到**餘弦相似度**（cosine similarity），範圍是 -1 到 1：

```formula
cos(a, b) = (a · b) / (|a| × |b|)
```

| 值 | 含義 |
|----|------|
| 1 | 方向完全相同（非常相似） |
| 0 | 垂直（無關） |
| -1 | 方向完全相反 |

```python
import math

def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

def cosine(a, b):
    return dot(a, b) / (math.sqrt(dot(a, a)) * math.sqrt(dot(b, b)))

# 假想的 3 維「詞向量」：[動物性, 王室性, 性別（男+ 女-）]
king  = [0.1, 0.9, 0.8]
queen = [0.1, 0.9, -0.8]
cat   = [0.9, 0.0, 0.0]
print(f"king·queen: {cosine(king, queen):.2f}")
print(f"king·cat:   {cosine(king, cat):.2f}")
```

在第七部分的 **RAG**（檢索增強生成）中，我們會用餘弦相似度在成千上萬篇文件裡找出和問題最相關的那幾篇。

## 4.5 矩陣：一張數字表格

**矩陣**（matrix）是一個按行和列排列的數字表格。`2 × 3` 矩陣有 2 行 3 列：

```python
M = [
    [1, 2, 3],
    [4, 5, 6],
]
rows, cols = len(M), len(M[0])
print(rows, cols)     # 2 3：這就是矩陣的「形狀」(shape)
print(M[1][2])        # 6：第 2 行第 3 列（下標從 0 開始）
```

一種很有用的看法：**矩陣是一摞向量**，每一行是一個向量。比如 5 個詞、每個詞用 4 維向量表示，就是一個 `5 × 4` 的矩陣。

### 轉置

把行變成列：`m × n` 變成 `n × m`。

```python
M = [[1, 2, 3],
     [4, 5, 6]]
T = [list(col) for col in zip(*M)]
print(T)      # [[1, 4], [2, 5], [3, 6]]
```

`zip(*M)` 把每一行拆開作為引數傳給 `zip`，正好按列取出——這是 Python 裡轉置的經典技巧。

## 4.6 矩陣乘向量：一次做很多個點積

矩陣 `W`（`m × n`）乘以向量 `x`（長度 `n`），結果是長度 `m` 的向量：**W 的每一行和 x 做一次點積**。

```text
        x = [1, 1, 2]
W = [[1, 0, 2],    →  1×1 + 0×1 + 2×2 = 5
     [0, 3, 1]]    →  0×1 + 3×1 + 1×2 = 5
W·x = [5, 5]
```

```python
def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

def matvec(W, x):
    return [dot(row, x) for row in W]

W = [[1, 0, 2],
     [0, 3, 1]]
print(matvec(W, [1, 1, 2]))    # [5, 5]
```

這就是**神經網路的一層**在做的事：輸入向量 `x`，乘以權重矩陣 `W`，得到輸出向量。`W` 的形狀決定了輸入、輸出的維度：`3` 維進，`2` 維出。

## 4.7 矩陣乘矩陣

兩個矩陣 `A`（`m × n`）和 `B`（`n × p`）相乘，結果 `C` 是 `m × p`：**C 的第 i 行第 j 列 = A 的第 i 行 和 B 的第 j 列 的點積**。

```text
A (2×3)        B (3×2)         C = A·B (2×2)
[1 2 3]        [7  8]          [1·7+2·9+3·11   1·8+2·10+3·12]   [ 58  64]
[4 5 6]   ×    [9 10]     =    [4·7+5·9+6·11   4·8+5·10+6·12] = [139 154]
               [11 12]
```

```python
def matmul(A, B):
    n = len(B)
    assert all(len(row) == n for row in A), "A 的列數必須等於 B 的行數"
    cols = list(zip(*B))                 # B 的每一列
    return [[sum(a * b for a, b in zip(row, col)) for col in cols] for row in A]

A = [[1, 2, 3],
     [4, 5, 6]]
B = [[7, 8],
     [9, 10],
     [11, 12]]
print(matmul(A, B))     # [[58, 64], [139, 154]]
```

> [!IMPORTANT]
> **形狀規則**：`(m × n) · (n × p) = (m × p)`。中間的 `n` 必須相等，才能相乘；結果取兩邊的 `m` 和 `p`。讀 AI 程式碼時，最常見的錯誤就是形狀對不上（shape mismatch）。養成習慣：**寫每一步時在註釋裡標出形狀**。

另外，矩陣乘法**不滿足交換律**：一般來說 `A·B ≠ B·A`（甚至形狀都可能對不上）。

## 4.8 為什麼 GPU 擅長這些？

一次矩陣乘法裡，成千上萬個點積**互不依賴**，可以同時計算——這正是 GPU 的強項（第 2 課）。一個大模型生成一個 token，要做的矩陣乘法加起來有幾十億到上千億次乘加運算。我們手寫的版本很慢，但原理完全一樣；NumPy 裡寫 `A @ B`，PyTorch 裡寫 `A @ B` 或 `torch.matmul(A, B)`，做的就是 `matmul` 這件事。

```python requires=numpy
import numpy as np
A = np.array([[1, 2, 3], [4, 5, 6]])
B = np.array([[7, 8], [9, 10], [11, 12]])
print(A @ B)
print(A.shape, B.shape, (A @ B).shape)
```

## 4.9 小結

- **向量**是一串數字，也是空間中的箭頭；運算：加法、數乘、長度（平方和開根號）。
- **點積**：對應相乘再相加；既是「加權求和」，也衡量「方向是否一致」。
- **餘弦相似度** = 點積 ÷ 兩個長度，範圍 -1～1，用來比較兩個向量有多像。
- **矩陣**是數字表格（一摞向量）；轉置用 `zip(*M)`。
- 矩陣乘向量 = 每一行和向量做點積 = 神經網路的一層。
- 矩陣乘法：`(m×n)·(n×p) = (m×p)`，C[i][j] = A 的第 i 行 · B 的第 j 列；不滿足交換律；時刻檢查形狀。

### 練習 4：形狀
