>
> ⏱ **Время**: 60 минут　|　📋 **Что нужно знать**: часть 1 (особенно урок 5 «Производные и градиенты»)

С этого урока мы по-настоящему *обучаем* модели. Сегодняшняя модель очень проста — прямая линия, — но способ обучения **ровно тот же**, что у GPT.

## 1.1 Задача: оценить цену квартиры по площади

Пусть есть данные о 5 квартирах:

| площадь x (десятки м²) | цена y (млн ₽) |
|------------------------|----------------|
| 1 | 3 |
| 2 | 5 |
| 3 | 7 |
| 4 | 9 |
| 5 | 11 |

Нужно правило, которое по площади новой квартиры оценит её цену. Если присмотреться, цена ≈ 2 × площадь + 1. Но мы хотим, чтобы **компьютер сам обнаружил** это в данных.

## 1.2 Пять главных идей

**① Модель**: функция с параметрами, которая получает x и выдаёт предсказание ŷ («игрек с крышкой»). Здесь — прямая:

```formula
ŷ = w · x + b
```

**② Параметры**: настраиваемые числа модели — здесь **w** (вес, наклон) и **b** (смещение, bias). У GPT миллиарды параметров; идея та же.

**③ Функция потерь** (loss function): одно число, показывающее, **насколько ошибаются** предсказания. Для регрессии обычно берут **среднеквадратичную ошибку** (MSE):

```formula
L = (1/N) · Σ (ŷᵢ − yᵢ)²
```

Ошибка каждого примера возводится в квадрат (так учитываются и положительные, и отрицательные ошибки, а большие наказываются сильнее), затем усредняется.

**④ Градиент**: производная функции потерь по каждому параметру — подсказывает, куда его сдвинуть.

**⑤ Цикл обучения** (training loop): повторяем «предсказать → вычислить потери → вычислить градиенты → обновить параметры».

```text
         ┌────────────────────────────────────────────────┐
         ▼                                                │
  предсказание ŷ с текущими параметрами ──► потери L ──► градиенты ──► параметры -= lr × градиент
```

## 1.3 Сначала вручную

```python
xs = [1, 2, 3, 4, 5]
ys = [3, 5, 7, 9, 11]

def predict(w, b, x):
    return w * x + b

def mse(w, b):
    return sum((predict(w, b, x) - y) ** 2 for x, y in zip(xs, ys)) / len(xs)

for w, b in [(0, 0), (1, 1), (2, 0), (2, 1)]:
    print(f"w={w}, b={b}  потери={mse(w, b):.2f}")
```

При `w=2, b=1` потери равны 0 — идеально. Но в реальных задачах так не угадаешь, и параметров больше двух. Поэтому — градиентный спуск.

## 1.4 Выводим градиенты

Функция потерь `L = (1/N) Σ (w·xᵢ + b − yᵢ)²`. Дифференцируем по w и b (цепное правило из урока 5 части 1: производная `(нечто)²` равна `2 × нечто × производная нечто`):

```formula
∂L/∂w = (2/N) · Σ (ŷᵢ − yᵢ) · xᵢ
∂L/∂b = (2/N) · Σ (ŷᵢ − yᵢ)
```

Интуиция: `ŷᵢ − yᵢ` — **ошибка** на каждом примере. Если предсказания в целом завышены (ошибки положительны), оба градиента положительны, и градиентный спуск уменьшает w и b — как и нужно.

## 1.5 Обучаем!

```python
xs = [1, 2, 3, 4, 5]
ys = [3, 5, 7, 9, 11]
N = len(xs)

w, b = 0.0, 0.0          # параметры начинают с 0
lr = 0.05                # скорость обучения

for step in range(1, 501):
    preds = [w * x + b for x in xs]                       # ① предсказание
    errors = [p - y for p, y in zip(preds, ys)]
    loss = sum(e * e for e in errors) / N                 # ② потери
    grad_w = 2 / N * sum(e * x for e, x in zip(errors, xs))   # ③ градиенты
    grad_b = 2 / N * sum(errors)
    w -= lr * grad_w                                      # ④ обновление
    b -= lr * grad_b
    if step in (1, 10, 50, 100, 500):
        print(f"шаг {step:3d}: потери = {loss:.6f}, w = {w:.4f}, b = {b:.4f}")

print(f"предсказанная цена для площади 6: {w * 6 + b:.2f}")
```

Потери падают, w приближается к 2, b — к 1. **Модель «выучила» правило по данным** — ответа ей никто не сообщал.

> [!IMPORTANT]
> Эти 15 строк — скелет любого обучения в глубоком обучении. При обучении GPT модель меняется с «прямой» на «трансформер», функция потерь — с MSE на «перекрёстную энтропию следующего токена», а градиенты автоматически считает обратное распространение, — но форма цикла **в точности та же**.

## 1.6 А если в данных шум?

Реальные данные никогда не лежат точно на прямой. Сгенерируем данные **со случайным шумом**:

```python
import random
random.seed(1)

xs = [i / 10 for i in range(50)]                              # от 0.0 до 4.9
ys = [3 * x - 2 + random.gauss(0, 0.5) for x in xs]          # истинное правило y = 3x - 2 плюс шум

w, b, lr = 0.0, 0.0, 0.05
N = len(xs)
for step in range(2000):
    errors = [(w * x + b) - y for x, y in zip(xs, ys)]
    w -= lr * 2 / N * sum(e * x for e, x in zip(errors, xs))
    b -= lr * 2 / N * sum(errors)

loss = sum(((w * x + b) - y) ** 2 for x, y in zip(xs, ys)) / N
print(f"выучено w = {w:.3f}, b = {b:.3f} (истинные 3 и -2), потери = {loss:.3f}")
```

Выученные параметры близки к истинным, но не совпадают — шум делает сами данные неопределёнными. И потери не доходят до 0, а останавливаются около уровня шума.

## 1.7 Скорость обучения и масштаб данных

Поменяйте в примере выше `lr` на `0.5` и запустите — потери станут `inf` или `nan` («не число»): **расходимость**. Как в уроке 5 части 1: скорость обучения слишком велика, и каждый шаг перескакивает минимум.

Ещё одна часто упускаемая причина — **масштаб признаков**. Если бы площадь была в квадратных метрах (десятки–сотни), а не в десятках м², `grad_w` умножался бы на большое `x`, градиент был бы огромным, и та же скорость обучения привела бы к расходимости. Поэтому входные данные обычно **стандартизируют** (вычитают среднее и делят на стандартное отклонение), чтобы все признаки были около 0 и в похожем масштабе.

## 1.8 Несколько признаков: векторная форма

Цена зависит не только от площади — ещё от этажа, возраста дома… При `d` признаках модель становится такой:

```formula
ŷ = w₁x₁ + w₂x₂ + … + w_d·x_d + b = w · x + b
```

Это **скалярное произведение** из урока 4 части 1! Сложите несколько примеров в матрицу — и предсказание станет **умножением матрицы на вектор**, ровно вычислением «линейного слоя» (`Linear` / `Dense`) нейросети.

```python
def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

# каждый пример: [площадь, этаж, возраст]
X = [[8, 3, 10], [12, 5, 2], [6, 1, 30]]
w = [2.0, 0.5, -0.1]
b = 1.0
print([round(dot(w, x) + b, 2) for x in X])
```

## 1.9 Обучающая и тестовая выборки

Хороший результат на обучающих данных **не означает хорошего результата на новых**. Ученик, вызубривший ответы домашки, проваливается, когда на экзамене другие задачи, — это **переобучение** (overfitting).

Поэтому данные всегда делят на две части:

- **обучающая выборка** (training set) — на ней подстраивают параметры;
- **тестовая выборка** (test set, или валидационная) — модель её **никогда не видит** при обучении; она нужна только для оценки.

О модели судят по **потерям на тестовой выборке**. Как бороться с переобучением — в уроке 6 части 2.

## 1.10 Итоги

- **Модель** — функция с **параметрами** (настраиваемыми числами); **функция потерь** измеряет, насколько она ошибается (для регрессии — MSE).
- Градиенты линейной регрессии `ŷ = w·x + b`: `∂L/∂w = (2/N)Σ(ŷ−y)x`, `∂L/∂b = (2/N)Σ(ŷ−y)`.
- **Цикл обучения** — предсказание → потери → градиенты → обновление, многократно, — скелет любого обучения в глубоком обучении.
- Слишком большая скорость обучения или плохо масштабированные признаки ведут к расходимости; входы обычно стандартизируют.
- При нескольких признаках предсказание — скалярное произведение `w·x + b`: линейный слой нейросети.
- Оценивайте на **тестовой выборке** и остерегайтесь **переобучения**.

### Задание 5: Зачем нужна функция потерь

Что делает функция потерь при обучении?

- Определяет, сколько у модели параметров
- Одним числом измеряет, насколько неверны текущие предсказания, а её градиент направляет обновление параметров
- Генерирует обучающие данные
- Ускоряет GPU

<summary>Ответ и разбор</summary>

</details>
