>
> ⏱ **預計用時**：60 分鐘　｜　📋 **前置知識**：第一部分（尤其是第 5 課「導數與梯度」）

從這一課開始，我們真正「訓練」模型。今天的模型非常簡單——一條直線——但訓練它的方法，和訓練 GPT 的方法**完全一樣**。

## 1.1 問題：根據面積估算房價

假設我們有 5 套房子的資料：

| 面積 x（十平方米） | 價格 y（十萬元） |
|-------------------|-----------------|
| 1 | 3 |
| 2 | 5 |
| 3 | 7 |
| 4 | 9 |
| 5 | 11 |

我們想要一個規則：給出一個新的面積，估算它的價格。觀察一下，似乎價格 ≈ 2 × 面積 + 1。但我們要讓**電腦自己從資料中發現**這個規律。

## 1.2 五個核心概念

**① 模型**（model）：一個帶引數的函式，輸入 x，輸出預測 ŷ（讀作 y-hat）。這裡我們用一條直線：

```formula
ŷ = w · x + b
```

**② 引數**（parameters）：模型裡可以調整的數字。這裡是 **w**（權重，斜率）和 **b**（偏置，截距）。GPT 有幾十億個引數，原理一樣。

**③ 損失函式**（loss function）：衡量預測**錯得有多離譜**的一個數字。迴歸問題最常用**均方誤差**（Mean Squared Error，MSE）：

```formula
L = (1/N) · Σ (ŷᵢ − yᵢ)²
```

每個樣本的誤差先平方（讓正負誤差都算作「錯」，並且大錯誤被重罰），再求平均。

**④ 梯度**（gradient）：損失對每個引數的導數，告訴我們每個引數該往哪個方向調。

**⑤ 訓練迴圈**（training loop）：重複「預測 → 算損失 → 算梯度 → 更新引數」。

```text
         ┌────────────────────────────────────────────┐
         ▼                                            │
  用當前引數預測 ŷ ──► 計算損失 L ──► 計算梯度 ──► 引數 -= 學習率 × 梯度
```

## 1.3 先手動試一試

```python
xs = [1, 2, 3, 4, 5]
ys = [3, 5, 7, 9, 11]

def predict(w, b, x):
    return w * x + b

def mse(w, b):
    return sum((predict(w, b, x) - y) ** 2 for x, y in zip(xs, ys)) / len(xs)

for w, b in [(0, 0), (1, 1), (2, 0), (2, 1)]:
    print(f"w={w}, b={b}  損失={mse(w, b):.2f}")
```

`w=2, b=1` 時損失為 0——完美。但真實問題裡我們無法這樣猜，引數也不止兩個。所以要用梯度下降。

## 1.4 推導梯度

損失是 `L = (1/N) Σ (w·xᵢ + b − yᵢ)²`。對 w 和 b 分別求導（用到第一部分第 5 課的鏈式法則：`(something)²` 的導數是 `2 × something × something 的導數`）：

```formula
∂L/∂w = (2/N) · Σ (ŷᵢ − yᵢ) · xᵢ
∂L/∂b = (2/N) · Σ (ŷᵢ − yᵢ)
```

直覺理解：`ŷᵢ − yᵢ` 是每個樣本的**誤差**。如果預測普遍偏大（誤差為正），兩個梯度都為正，梯度下降會把 w 和 b 調小——正好。

## 1.5 訓練！

```python
xs = [1, 2, 3, 4, 5]
ys = [3, 5, 7, 9, 11]
N = len(xs)

w, b = 0.0, 0.0          # 引數從 0 開始
lr = 0.05                # 學習率

for step in range(1, 501):
    preds = [w * x + b for x in xs]                       # ① 預測
    errors = [p - y for p, y in zip(preds, ys)]
    loss = sum(e * e for e in errors) / N                 # ② 損失
    grad_w = 2 / N * sum(e * x for e, x in zip(errors, xs))   # ③ 梯度
    grad_b = 2 / N * sum(errors)
    w -= lr * grad_w                                      # ④ 更新
    b -= lr * grad_b
    if step in (1, 10, 50, 100, 500):
        print(f"第 {step:3d} 步：損失 = {loss:.6f}，w = {w:.4f}，b = {b:.4f}")

print(f"面積 6 的預測價格：{w * 6 + b:.2f}")
```

損失一路下降，w 逼近 2，b 逼近 1。**模型從資料中「學會」了這個規律**——沒有任何人告訴它答案。

> [!IMPORTANT]
> 這 15 行程式碼，就是所有深度學習訓練的骨架。訓練 GPT 時：模型從「一條直線」換成「Transformer」，損失從 MSE 換成「下一個 token 的交叉熵」，梯度由反向傳播自動計算——但迴圈的結構**一模一樣**。

## 1.6 資料有噪聲怎麼辦？

真實資料不會完美地落在一條直線上。我們生成一些**帶隨機噪聲**的資料來試試：

```python
import random
random.seed(1)

xs = [i / 10 for i in range(50)]                              # 0.0 ~ 4.9
ys = [3 * x - 2 + random.gauss(0, 0.5) for x in xs]          # 真實規律 y = 3x - 2，再加噪聲

w, b, lr = 0.0, 0.0, 0.05
N = len(xs)
for step in range(2000):
    errors = [(w * x + b) - y for x, y in zip(xs, ys)]
    w -= lr * 2 / N * sum(e * x for e, x in zip(errors, xs))
    b -= lr * 2 / N * sum(errors)

loss = sum(((w * x + b) - y) ** 2 for x, y in zip(xs, ys)) / N
print(f"學到的 w = {w:.3f}，b = {b:.3f}（真實值 3 和 -2），損失 = {loss:.3f}")
```

學到的引數接近真實值，但不會完全相等——噪聲讓資料本身就有不確定性。損失也不會降到 0，而是停在噪聲的水平附近。

## 1.7 學習率與資料縮放

試著把上面例子的 `lr` 改成 `0.5`，再執行——損失會變成 `inf` 或 `nan`（不是一個數）：**發散了**。原因是第一部分第 5 課講過的：學習率太大，每一步都衝過頭。

還有一個常被忽視的原因：**特徵的尺度**。如果面積用「平方米」（數值幾十到幾百）而不是「十平方米」，`grad_w` 裡乘了一個很大的 `x`，梯度會變得很大，同樣的學習率就會發散。所以實踐中常把輸入**標準化**（減去平均值、除以標準差），讓各個特徵的數值都在 0 附近、尺度相近。

## 1.8 多個特徵：向量形式

房價不只取決於面積，還有樓層、房齡……有 `d` 個特徵時，模型變成：

```formula
ŷ = w₁x₁ + w₂x₂ + … + w_d·x_d + b = w · x + b
```

就是第一部分第 4 課的**點積**！把多個樣本疊成矩陣，預測就變成**矩陣乘向量**。這正是神經網路裡「線性層」（`Linear` / `Dense`）的計算。

```python
def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

# 每個樣本：[面積, 樓層, 房齡]
X = [[8, 3, 10], [12, 5, 2], [6, 1, 30]]
w = [2.0, 0.5, -0.1]
b = 1.0
print([round(dot(w, x) + b, 2) for x in X])
```

## 1.9 訓練集與測試集

模型在訓練資料上表現好，**不代表在新資料上也好**。就像學生把習題答案背下來，考試換了題目就不會了——這叫**過擬合**（overfitting）。

所以總是把資料分成兩份：

- **訓練集**（training set）：用來調引數；
- **測試集**（test set，或驗證集 validation set）：模型訓練時**從來沒見過**，只用來評估效果。

衡量模型好壞，看的是**測試集上的損失**。第二部分第 6 課會詳細講如何避免過擬合。

## 1.10 小結

- **模型**是帶引數的函式；**引數**是可調的數字；**損失函式**衡量錯得多離譜（迴歸用 MSE）。
- 線性迴歸 `ŷ = w·x + b` 的梯度：`∂L/∂w = (2/N)Σ(ŷ−y)x`，`∂L/∂b = (2/N)Σ(ŷ−y)`。
- **訓練迴圈**：預測 → 損失 → 梯度 → 更新，重複——這就是所有深度學習訓練的骨架。
- 學習率太大、特徵尺度太大都會讓訓練發散；常對輸入做標準化。
- 多個特徵時預測是點積 `w·x + b`，即神經網路的「線性層」。
- 用**測試集**評估模型，警惕**過擬合**。

### 練習 4：過擬合

一個模型在訓練集上的損失幾乎為 0，但在測試集上的損失很大。這說明什麼？

- 模型完美，可以上線
- 模型過擬合了：記住了訓練資料，沒有學到通用規律
- 測試集出錯了，應該刪掉
- 學習率太小

<details>
<summary>答案與解析</summary>

這是典型的過擬合。解決辦法包括：更多資料、更簡單的模型、正則化、提前停止等（第 6 課）。
</details>

### 練習 5：損失函式的作用

在訓練中，損失函式的作用是？

- 決定模型有多少引數
- 用一個數字衡量當前預測錯得有多離譜，並透過它的梯度指導引數更新
- 生成訓練資料
- 加快 GPU 的速度

<details>
<summary>答案與解析</summary>

損失把「好不好」變成一個可以求導的數字，梯度下降就是讓這個數字不斷變小。
</details>
