# 1. 第一个会学习的模型：用梯度下降拟合直线

> 🎯 **本课目标**：亲手训练第一个模型；理解「模型、参数、损失函数、梯度、训练循环」这五个贯穿全课程的概念；推导并实现线性回归的梯度；体会数据缩放和学习率对训练的影响；知道训练集与测试集的区别。
>
> ⏱ **预计用时**：60 分钟　｜　📋 **前置知识**：第一部分（尤其是第 5 课「导数与梯度」）

从这一课开始，我们真正「训练」模型。今天的模型非常简单——一条直线——但训练它的方法，和训练 GPT 的方法**完全一样**。

## 1.1 问题：根据面积估算房价

假设我们有 5 套房子的数据：

| 面积 x（十平方米） | 价格 y（十万元） |
|-------------------|-----------------|
| 1 | 3 |
| 2 | 5 |
| 3 | 7 |
| 4 | 9 |
| 5 | 11 |

我们想要一个规则：给出一个新的面积，估算它的价格。观察一下，似乎价格 ≈ 2 × 面积 + 1。但我们要让**电脑自己从数据中发现**这个规律。

## 1.2 五个核心概念

**① 模型**（model）：一个带参数的函数，输入 x，输出预测 ŷ（读作 y-hat）。这里我们用一条直线：

```formula
ŷ = w · x + b
```

**② 参数**（parameters）：模型里可以调整的数字。这里是 **w**（权重，斜率）和 **b**（偏置，截距）。GPT 有几十亿个参数，原理一样。

**③ 损失函数**（loss function）：衡量预测**错得有多离谱**的一个数字。回归问题最常用**均方误差**（Mean Squared Error，MSE）：

```formula
L = (1/N) · Σ (ŷᵢ − yᵢ)²
```

每个样本的误差先平方（让正负误差都算作「错」，并且大错误被重罚），再求平均。

**④ 梯度**（gradient）：损失对每个参数的导数，告诉我们每个参数该往哪个方向调。

**⑤ 训练循环**（training loop）：重复「预测 → 算损失 → 算梯度 → 更新参数」。

```text
         ┌────────────────────────────────────────────┐
         ▼                                            │
  用当前参数预测 ŷ ──► 计算损失 L ──► 计算梯度 ──► 参数 -= 学习率 × 梯度
```

## 1.3 先手动试一试

```python
xs = [1, 2, 3, 4, 5]
ys = [3, 5, 7, 9, 11]

def predict(w, b, x):
    return w * x + b

def mse(w, b):
    return sum((predict(w, b, x) - y) ** 2 for x, y in zip(xs, ys)) / len(xs)

for w, b in [(0, 0), (1, 1), (2, 0), (2, 1)]:
    print(f"w={w}, b={b}  损失={mse(w, b):.2f}")
```

`w=2, b=1` 时损失为 0——完美。但真实问题里我们无法这样猜，参数也不止两个。所以要用梯度下降。

## 1.4 推导梯度

损失是 `L = (1/N) Σ (w·xᵢ + b − yᵢ)²`。对 w 和 b 分别求导（用到第一部分第 5 课的链式法则：`(something)²` 的导数是 `2 × something × something 的导数`）：

```formula
∂L/∂w = (2/N) · Σ (ŷᵢ − yᵢ) · xᵢ
∂L/∂b = (2/N) · Σ (ŷᵢ − yᵢ)
```

直觉理解：`ŷᵢ − yᵢ` 是每个样本的**误差**。如果预测普遍偏大（误差为正），两个梯度都为正，梯度下降会把 w 和 b 调小——正好。

## 1.5 训练！

```python
xs = [1, 2, 3, 4, 5]
ys = [3, 5, 7, 9, 11]
N = len(xs)

w, b = 0.0, 0.0          # 参数从 0 开始
lr = 0.05                # 学习率

for step in range(1, 501):
    preds = [w * x + b for x in xs]                       # ① 预测
    errors = [p - y for p, y in zip(preds, ys)]
    loss = sum(e * e for e in errors) / N                 # ② 损失
    grad_w = 2 / N * sum(e * x for e, x in zip(errors, xs))   # ③ 梯度
    grad_b = 2 / N * sum(errors)
    w -= lr * grad_w                                      # ④ 更新
    b -= lr * grad_b
    if step in (1, 10, 50, 100, 500):
        print(f"第 {step:3d} 步：损失 = {loss:.6f}，w = {w:.4f}，b = {b:.4f}")

print(f"面积 6 的预测价格：{w * 6 + b:.2f}")
```

损失一路下降，w 逼近 2，b 逼近 1。**模型从数据中「学会」了这个规律**——没有任何人告诉它答案。

> [!IMPORTANT]
> 这 15 行代码，就是所有深度学习训练的骨架。训练 GPT 时：模型从「一条直线」换成「Transformer」，损失从 MSE 换成「下一个 token 的交叉熵」，梯度由反向传播自动计算——但循环的结构**一模一样**。

## 1.6 数据有噪声怎么办？

真实数据不会完美地落在一条直线上。我们生成一些**带随机噪声**的数据来试试：

```python
import random
random.seed(1)

xs = [i / 10 for i in range(50)]                              # 0.0 ~ 4.9
ys = [3 * x - 2 + random.gauss(0, 0.5) for x in xs]          # 真实规律 y = 3x - 2，再加噪声

w, b, lr = 0.0, 0.0, 0.05
N = len(xs)
for step in range(2000):
    errors = [(w * x + b) - y for x, y in zip(xs, ys)]
    w -= lr * 2 / N * sum(e * x for e, x in zip(errors, xs))
    b -= lr * 2 / N * sum(errors)

loss = sum(((w * x + b) - y) ** 2 for x, y in zip(xs, ys)) / N
print(f"学到的 w = {w:.3f}，b = {b:.3f}（真实值 3 和 -2），损失 = {loss:.3f}")
```

学到的参数接近真实值，但不会完全相等——噪声让数据本身就有不确定性。损失也不会降到 0，而是停在噪声的水平附近。

## 1.7 学习率与数据缩放

试着把上面例子的 `lr` 改成 `0.5`，再运行——损失会变成 `inf` 或 `nan`（不是一个数）：**发散了**。原因是第一部分第 5 课讲过的：学习率太大，每一步都冲过头。

还有一个常被忽视的原因：**特征的尺度**。如果面积用「平方米」（数值几十到几百）而不是「十平方米」，`grad_w` 里乘了一个很大的 `x`，梯度会变得很大，同样的学习率就会发散。所以实践中常把输入**标准化**（减去平均值、除以标准差），让各个特征的数值都在 0 附近、尺度相近。

## 1.8 多个特征：向量形式

房价不只取决于面积，还有楼层、房龄……有 `d` 个特征时，模型变成：

```formula
ŷ = w₁x₁ + w₂x₂ + … + w_d·x_d + b = w · x + b
```

就是第一部分第 4 课的**点积**！把多个样本叠成矩阵，预测就变成**矩阵乘向量**。这正是神经网络里「线性层」（`Linear` / `Dense`）的计算。

```python
def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

# 每个样本：[面积, 楼层, 房龄]
X = [[8, 3, 10], [12, 5, 2], [6, 1, 30]]
w = [2.0, 0.5, -0.1]
b = 1.0
print([round(dot(w, x) + b, 2) for x in X])
```

## 1.9 训练集与测试集

模型在训练数据上表现好，**不代表在新数据上也好**。就像学生把习题答案背下来，考试换了题目就不会了——这叫**过拟合**（overfitting）。

所以总是把数据分成两份：

- **训练集**（training set）：用来调参数；
- **测试集**（test set，或验证集 validation set）：模型训练时**从来没见过**，只用来评估效果。

衡量模型好坏，看的是**测试集上的损失**。第二部分第 6 课会详细讲如何避免过拟合。

## 1.10 小结

- **模型**是带参数的函数；**参数**是可调的数字；**损失函数**衡量错得多离谱（回归用 MSE）。
- 线性回归 `ŷ = w·x + b` 的梯度：`∂L/∂w = (2/N)Σ(ŷ−y)x`，`∂L/∂b = (2/N)Σ(ŷ−y)`。
- **训练循环**：预测 → 损失 → 梯度 → 更新，重复——这就是所有深度学习训练的骨架。
- 学习率太大、特征尺度太大都会让训练发散；常对输入做标准化。
- 多个特征时预测是点积 `w·x + b`，即神经网络的「线性层」。
- 用**测试集**评估模型，警惕**过拟合**。

### 练习 4：过拟合

一个模型在训练集上的损失几乎为 0，但在测试集上的损失很大。这说明什么？

- 模型完美，可以上线
- 模型过拟合了：记住了训练数据，没有学到通用规律

- 学习率太小

<summary>答案与解析</summary>

### 练习 5：损失函数的作用

在训练中，损失函数的作用是？

- 决定模型有多少参数
- 用一个数字衡量当前预测错得有多离谱，并通过它的梯度指导参数更新
