Модель прошлого урока выдавала **число** (цену). Во многих задачах нужна **категория**: спам ли это письмо? Что на картинке — кошка, собака или птица? И главное — **какой токен словаря идёт следующим?** Языковая модель по сути — классификатор с десятками тысяч классов.

## 2.1 Бинарная классификация: выдаём вероятность

Чтобы решить, спам ли письмо, хочется, чтобы модель выдавала **вероятность** этого — число от 0 до 1. Но линейная модель `z = w·x + b` выдаёт любое действительное число. Нужна функция, которая «сжимает» его в 0–1, — **сигмоида**:

```formula
σ(z) = 1 / (1 + e^(−z))
```

```python
import math

def sigmoid(z):
    return 1 / (1 + math.exp(-z))

for z in [-6, -2, 0, 2, 6]:
    print(f"σ({z:>2}) = {sigmoid(z):.4f}")
```

```text
       1 ┤                 ●●●●●
         │              ●●
     0.5 ┤ - - - - - - ●- - - - -     большое z → почти 1
         │          ●●                 z = 0    → 0.5
       0 ┤ ●●●●●●●●                    малое z  → почти 0
         └────────────┬───────────
                      0
```

«Линейная модель + сигмоида» — это **логистическая регрессия**: называется *регрессией*, а решает задачу классификации.

### Бинарная перекрёстная энтропия

При метках `y` (0 или 1) и предсказании `p = σ(z)` функция потерь — перекрёстная энтропия из урока 6 части 1:

```formula
L = −[ y·log p + (1 − y)·log(1 − p) ]
```

При `y = 1` это `−log p`, при `y = 0` — `−log(1 − p)`: всё та же «удивлённость правильным ответом».

## 2.2 Много классов: softmax-регрессия

При `K` классах (10 для рукописных цифр или 50 000 токенов для языковой модели) модель выдаёт `K` оценок (логитов), и **softmax** превращает их в распределение вероятностей:

```text
вход x ──► линейный слой: K оценок z = W·x + b ──► softmax ──► K вероятностей ──► перекрёстная энтропия
           форма W — K × d                                    (сумма 1)         −log p[правильный класс]
```

Это **softmax-регрессия** (мультиномиальная логистическая регрессия). **Последний слой** языковой модели устроен ровно так: выходной вектор трансформера умножается на матрицу `V × d`, получаются `V` логитов, затем softmax.

## 2.3 Самый важный градиент: p − y

Для softmax + перекрёстной энтропии градиент по логитам **поразительно прост**:

```formula
∂L/∂zₖ = pₖ − yₖ
```

где `p` — вероятности softmax, а `y` — **one-hot-вектор** правильного ответа (1 на месте правильного класса, 0 в остальных).

```python
import math

def softmax(z):
    m = max(z)
    e = [math.exp(v - m) for v in z]
    s = sum(e)
    return [v / s for v in e]

z = [2.0, 1.0, 0.1]          # оценки для 3 классов
target = 0                    # правильный ответ — класс 0
p = softmax(z)
y = [1 if k == target else 0 for k in range(len(z))]     # one-hot: [1, 0, 0]
grad = [pk - yk for pk, yk in zip(p, y)]
print("вероятности:", [round(v, 4) for v in p])
print("градиент:   ", [round(v, 4) for v in grad])
```

Интуиция:

- у **правильного класса** градиент `p − 1` отрицателен → градиентный спуск **повышает** его оценку;
- у **неправильных** градиент `p` положителен → их оценки **понижаются**;
- чем лучше предсказание (чем ближе правильное p к 1), тем меньше градиент и тем меньше поправка.

> [!IMPORTANT]
> Запомните **p − y**. При обучении языковой модели градиент выходного слоя в каждой позиции считается именно так: распределение вероятностей модели минус вектор с единицей на месте правильного токена.

Проверим формулу численно (способом из урока 5 части 1):

```python
import math

def softmax(z):
    m = max(z)
    e = [math.exp(v - m) for v in z]
    s = sum(e)
    return [v / s for v in e]

def loss(z, target):
    return -math.log(softmax(z)[target])

z, target, h = [2.0, 1.0, 0.1], 0, 1e-5
numeric = []
for k in range(len(z)):
    zp = z[:]; zp[k] += h
    zm = z[:]; zm[k] -= h
    numeric.append((loss(zp, target) - loss(zm, target)) / (2 * h))
print("численный градиент:", [round(v, 4) for v in numeric])
```

Оба способа совпадают.

## 2.4 Практика: обучаем двумерный классификатор

Сгенерируем два облака точек — класс 0 слева внизу, класс 1 справа вверху — и обучим softmax-регрессию их различать.

```python
import math
import random
random.seed(0)

# данные: каждый пример (x1, x2) с меткой 0 или 1
data = [((random.gauss(-1, 0.7), random.gauss(-1, 0.7)), 0) for _ in range(50)]
data += [((random.gauss(1, 0.7), random.gauss(1, 0.7)), 1) for _ in range(50)]

K, D = 2, 2
W = [[0.0] * D for _ in range(K)]      # K × D
b = [0.0] * K
lr = 0.5

def softmax(z):
    m = max(z)
    e = [math.exp(v - m) for v in z]
    s = sum(e)
    return [v / s for v in e]

def forward(x):
    z = [sum(W[k][d] * x[d] for d in range(D)) + b[k] for k in range(K)]
    return softmax(z)

for epoch in range(1, 31):
    gW = [[0.0] * D for _ in range(K)]
    gb = [0.0] * K
    total_loss = 0.0
    for x, label in data:
        p = forward(x)
        total_loss += -math.log(p[label])
        for k in range(K):
            g = p[k] - (1 if k == label else 0)        # p − y
            gb[k] += g
            for d in range(D):
                gW[k][d] += g * x[d]                   # цепное правило: ∂z/∂W = x
    n = len(data)
    for k in range(K):
        b[k] -= lr * gb[k] / n
        for d in range(D):
            W[k][d] -= lr * gW[k][d] / n
    if epoch % 10 == 0:
        acc = sum(max(range(K), key=lambda k: forward(x)[k]) == label for x, label in data) / n
        print(f"эпоха {epoch}: средние потери {total_loss / n:.4f}, точность {acc:.0%}")
```

Через несколько десятков эпох точность близка к 100%. **Эпоха** (epoch) — один полный проход по обучающим данным.

### Точность

Кроме потерь, классификацию часто оценивают **точностью** (accuracy): долей примеров, у которых предсказанный класс (самый вероятный, argmax) совпал с истинным. Потери нужны для градиентов при обучении; точность понятнее людям.

## 2.5 От классификации к языковым моделям

Замените `K` на размер словаря (например, 50 000), а вход `x` — на «вектор, описывающий предыдущий текст», и получится последний шаг языковой модели:

| | классификатор точек | языковая модель |
|---|---|---|
| число классов K | 2 | размер словаря (десятки–сотни тысяч) |
| вход x | координаты (x1, x2) | понимание контекста трансформером (вектор из тысяч чисел) |
| выход | 2 вероятности | вероятность каждого токена быть следующим |
| потери | перекрёстная энтропия | перекрёстная энтропия (среднее по позициям) |
| градиент | p − y | p − y |

## 2.6 Итоги

- **Сигмоида** `1/(1+e^(−z))` сжимает любое число в 0–1; линейная модель + сигмоида = **логистическая регрессия** (бинарная), обучается на бинарной перекрёстной энтропии.
- Много классов: линейный слой даёт K логитов → **softmax** → перекрёстная энтропия: **softmax-регрессия**, она же выходной слой языковой модели.
- Градиент softmax + перекрёстной энтропии по логитам равен **p − y** (y — one-hot).
- При обучении градиенты по примерам суммируют, усредняют и обновляют параметры; **эпоха** — полный проход по данным.
- Классификацию часто оценивают **точностью** — долей совпадений argmax с меткой.

### Задание 4: Куда направлен градиент

При обучении с softmax + перекрёстной энтропией градиент `p − 1` логита **правильного класса** всегда:

- положителен, поэтому его оценка понижается
- отрицателен (или 0), поэтому градиентный спуск повышает его оценку
- всегда равен 0
- зависит от скорости обучения

<details>
<summary>Ответ и разбор</summary>

p не больше 1, поэтому `p − 1 ≤ 0`. Градиентный спуск вычитает «скорость обучения × отрицательное число», то есть повышает оценку этого класса — модель всё сильнее склоняется к правильному ответу.
</details>
